# 오피스 프로그램과 견준 빠진 기능 (2026-11-01, v0.1.8 기준)

Word·Excel·PowerPoint·한컴 한글·PDF 뷰어가 기본으로 하는 일 가운데 Office Kit에 없는 것을 정리했다.
문서 안 편집 기능(글자·문단 서식, 표, 그림, 수식, 메모, 변경 내용 추적, 찾아 바꾸기, 되돌리기, 확대 등)은
편집기(한글: rhwp-studio, Word·Excel·PowerPoint: ONLYOFFICE)가 이미 갖고 있어 여기서는 **프로그램 바깥 틀**(파일·창·인쇄·저장·복구)을 본다.

## 만든 것 (v0.1.9)

- [x] 한글 편집 창: **인쇄**(Ctrl+P — 쪽 그림으로 Windows 인쇄 대화상자) · **PDF로 저장**(다른 이름으로 저장 ▾ → PDF)
- [x] 한글 편집 창: **자동 저장·복구** (10분, 복구/버리기)
- [x] 두 편집 창: **Ctrl+O 열기 · Ctrl+N 새 문서**
- [x] **서식 파일로 새 문서**: 회의록·업무 보고서·기안문(공문)·업무 계획서·이력서·안내문·일정표·발표 자료·예산표·명단
- [x] **PDF 도구**: 합치기·쪽 뽑기·쪽 지우기·돌리기 (앱 도구 메뉴, `office-kit pdf`, MCP `office_pdf_tools`)
- [x] 주 창 **인쇄**(Ctrl+P): 한글은 인쇄 대화상자, 그 밖은 PDF로 만들어 PDF 프로그램에서
- [x] 최근 문서 **고정**

## 처음 세운 순서

1. **한글 편집 창: 인쇄·PDF로 저장** — 편집 중인 내용(저장 안 한 것 포함)을 내장 엔진으로 PDF로 만들어, 인쇄는 기본 PDF 앱으로, PDF로 저장은 저장 대화상자로.
2. **한글 편집 창: 자동 저장·복구** — 문서·표·슬라이드 편집 창과 같게 10분마다 복구 사본(원본은 그대로), 다시 열 때 복구/버리기.
3. **편집 창에서 Ctrl+O(열기)·Ctrl+N(새 문서)** — 두 편집 창 모두. 연 문서는 새 편집 창으로.
4. **서식 파일로 새 문서** — 회의록·보고서·공문(기안문)·업무 계획서·이력서·발표 자료·예산표 같은 기본 서식 (한글·Word·PowerPoint·Excel).
5. **PDF 도구** — 합치기, 쪽 뽑기(나누기), 회전, 쪽 지우기 (인터넷·프로그램 없이).
6. **주 창 인쇄** — 열린 문서를 PDF로 만들어 기본 PDF 앱으로 (한글은 내장 엔진, Word·Excel·PowerPoint는 설치된 프로그램).
7. **최근 문서 고정**.

## 이번에 하지 않는 것 (까닭)

- **맞춤법 검사**: 한국어 Hunspell 사전(라이선스·용량)과 편집기 사전 형식 변환이 필요하다. 따로 검토.
- **암호 문서 열기**: 암호를 받아 푸는 경로(편집기·변환기)가 커서 따로.
- **자동 업데이트**: 저장소가 비공개라 앱이 토큰 없이 Release를 받을 수 없다 (공개 배포 저장소를 두면 가능).
- **문서 속성 편집**: 쓰임이 적어 뒤로.
