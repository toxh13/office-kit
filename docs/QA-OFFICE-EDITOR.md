# 문서·표·슬라이드 편집 창 확인 목록 (QA)

> 대상: Word·Excel·PowerPoint 형식(docx·xlsx·pptx) 직접 편집 창. 설계는 [OFFICE-EDITOR-DESIGN.md](OFFICE-EDITOR-DESIGN.md) 10장.
> 릴리스 후보마다 이 목록을 처음부터 끝까지 한 번 돈다. 자동 시험이 하는 것은 사람이 다시 하지 않는다.

## 한눈에

- **자동으로 확인하는 것** (`test/office-editor-e2e.test.mjs`, `scripts/dev/office-e2e.mjs`): 실제 앱 + CDP 입력.
  - 형식 3 × 만든 방법 3 문서를 열고 → 한국어 입력·굵게·표 행/수식·새 슬라이드 → Ctrl+S → 파일 내용 확인.
  - 밖으로 나간 요청 0건, WebRTC 후보 0개, 자동 저장은 사본에만, 바깥 변경 띠, 원래대로, 멈춤 뒤 복구, 닫기 확인.
  - (Office가 있을 때) 저장한 파일을 Word·Excel·PowerPoint에서 경고·복구 창 없이 엄격히 열기.
- **사람이 확인하는 것** (아래 2장): **실제 MS 한국어 IME**, 복사·붙여넣기, 인쇄, 큰 문서, 다크 모드·고해상도, 창 여러 개, 설치본.
- CDP의 한국어 입력은 **IME 흉내**다 (조합 글자를 바로 넣음). 실제 IME의 조합·확정 순서는 사람 시험으로만 판정한다.
- **다음 행동 하나**: 자동 시험을 돌린다 → 통과하면 2장 사람 시험.

## 1. 자동 시험 돌리기

준비: `npm run office-editor:build`(묶음 `vendor/office-editor`), Windows 11, Node 24.

| 무엇 | 명령 | 시간 |
|---|---|---|
| 도우미 시험만 (늘 돈다) | `node --test test/office-editor-e2e.test.mjs` | 몇 초 |
| 실제 앱 e2e (창이 뜨고 닫힌다) | `$env:OFFICEKIT_EDITOR_SMOKE='1'; node --test test/office-editor-e2e.test.mjs` | 약 5분 |
| + Office로 만든 문서·COM 엄격 열기 | `$env:OFFICEKIT_EDITOR_SMOKE='1'; $env:OFFICEKIT_COM_TESTS='1'; node --test test/office-editor-e2e.test.mjs` | 약 7분 |
| 손으로 (보고서·화면을 남김) | `node scripts/dev/office-e2e.mjs --out tmp/office-e2e/run1` | 약 7분 |

- 보고서: `<out>/report.json` (확인마다 `group`·`name`·`ok`·`info`), 화면: `<out>/shots/*.png` (열기·고친 뒤·저장 뒤).
  시험 묶음에서 남기려면 `OFFICEKIT_SMOKE_OUT=<폴더>`.
- 손으로 돌릴 때 고를 것: `--formats docx,xlsx,pptx` `--methods create,blank,office` `--no-com` `--no-flows` `--office-docs <폴더>`(Office로 만든 `office.docx·xlsx·pptx`를 COM 대신) `--keep`(사용자 데이터 폴더 남김).
- COM 없이도 `test/fixtures/office-editor/office.docx·xlsx·pptx`(Office로 만든 고정 파일)가 있으면 시험 묶음이 세 번째 방법을 그 파일로 돈다.
  만들기 (Office가 있는 PC에서 한 번): `node -e "import('./scripts/dev/office-e2e.mjs').then((m) => console.log(m.makeOfficeDocs('tmp/office-made')))"`
- **COM을 쓰는 동안 Word·Excel·PowerPoint를 켜 두지 않는다.** 떠 있으면 시험이 문서 만들기를 건너뛰고(사용자 Office를 건드리지 않음), PowerPoint 엄격 열기는 `busy`로 실패한다.
- 시험 중에 뜨는 확인창('저장할까요?', '멈췄습니다')은 UI Automation으로 단추에 메시지만 보낸다. **키보드·마우스 입력을 보내지 않으므로** 다른 창을 써도 되지만, 편집 창이 앞으로 나오므로 그동안은 PC를 쓰지 않는 편이 좋다.
- 한컴오피스 COM은 쓰지 않는다 (한글 문서 확인은 rhwp 엔진으로만).

### 자동 시험이 확인하는 것

| 묶음 | 확인 |
|---|---|
| 문서마다 (`create-*`, `blank-*`, `office-*`) | 편집 창이 kind `office`로 열림 · 창 제목 `<파일> - 문서/표/슬라이드 편집 (Office Kit)`(고치면 앞에 `* `, 'ONLYOFFICE' 없음) · 고치면 '저장 안 됨', 주 창 상태 막대 '… 창 열림 · 저장 안 됨' · AI 보내기가 `EDITOR_DIRTY`로 막힘 · Ctrl+S → 파일 저장·'저장됨'·복구 사본 없음 · `readDocument(engine:'file')`로 고친 내용 · 굵게(XML) · 밖으로 나간 요청 0건 · Ctrl+W로 묻지 않고 닫힘 |
| 문서(docx) | 끝에 문단 둘(첫째 굵게, 둘째 보통, IME 흉내 '판정') · 표에 새 행(있는 표는 `addRowBelow`, 새 문서는 표를 넣고 마지막 칸 Tab) · 혼자 남은 `vMerge restart` 없음 |
| 표(xlsx) | `제주 10 20 30 =SUM(…)` → 60 · 굵게 · 위에 행 삽입 뒤 수식 참조가 밀림 · IME 흉내 '세종' 행 |
| 슬라이드(pptx) | 첫 슬라이드 제목 뒤 굵은 글 · Ctrl+M 새 슬라이드 + 글 · IME 흉내 '한글' |
| 형식마다 한 번 | WebRTC: host·앱·편집기 세 틀 모두 STUN 서버를 줘도 후보 0개 |
| COM (`OFFICEKIT_COM_TESTS=1`) | `scripts/dev/strict-open.ps1`(경고 모두 켬, 복구 끔, 감시 타이머)로 열림 · Word: 문단 굵게·표 `Rows.Item` 됨 · Excel: `**제주**`·`60 {=SUM(…)}` · PowerPoint: 슬라이드 수·글 |
| 흐름 (`flow-docx`) | 바깥 변경(고친 것 없음) → 저절로 다시 불러옴 · 고친 뒤 바깥 변경 → 띠 '다시 불러오기 / 내 편집 유지' · 자동 저장(앱 틀 시계를 11분 앞으로) → `userData/office-drafts`에만, 파일 그대로, '저장 안 됨' 유지 · 화면 멈춤(렌더러 죽임) → 안내 → 다시 열림 → '자동 저장된 편집 내용이 있습니다' → 복구 → 저장 · 주 창 '원래대로'(고친 것 없음 → 다시 불러옴 / 고침 → 띠) · 닫기 확인 '저장 / 저장 안 함 / 취소' 세 갈래 |
| 전체 | 편집 창들의 모든 요청(틀·워커 포함, CDP)이 `127.0.0.x`·`blob:`·`data:`뿐 · 세션이 막은 요청 0건(main 로그 '막은 요청') |

## 2. 사람 시험 (출시 관문)

결과는 맨 아래 표에 적는다. 하나라도 ✗면 출시하지 않는다 (알려진 한계는 3장 — ✗가 아님).

### 2.1 실제 MS 한국어 IME (꼭)

준비: Windows 설정 → 시간 및 언어 → 언어 → 한국어 → Microsoft 입력기. 문서 하나씩 새로 만든다 (주 창 '새 문서' → '만든 뒤 바로 편집 창 열기').

- [ ] **두벌식**: 문서 본문에 `한글 입력 시험입니다. 값=7, ABC 섞어 쓰기.` → 글자 겹침·빠짐 없음, 마지막 글자까지 들어감
- [ ] 조합 중에 **Backspace**(자모 하나씩 지워짐), **방향키**(조합 확정 뒤 이동), **Enter**(확정 뒤 줄 바꿈)
- [ ] 조합 중에 **Ctrl+S** → 저장한 파일에 마지막 글자가 들어 있음 (Word로 열어 확인)
- [ ] 조합 중에 **마우스로 다른 곳 클릭** → 조합 글자가 남거나 두 번 들어가지 않음
- [ ] **한/영 키** 전환을 빠르게 반복하며 입력 (`가a나b다c`)
- [ ] **한자 변환**: `한국` 입력 뒤 한자 키 → 후보 창 → `韓國` 고르기
- [ ] **세벌식**(최종 또는 390)으로 바꿔 같은 문장 → 같은 결과
- [ ] 표 셀 안, 머리글·바닥글 안, 메모(댓글) 안에서 입력
- [ ] 표 편집: 셀에 바로 입력, F2로 셀 편집, 수식 입력줄에 `=SUM(` 뒤 한글 시트 이름 입력, 셀 이동(Tab·Enter)과 조합 확정
- [ ] 슬라이드 편집: 제목 틀, 본문 틀, 새로 그린 글상자, 표 셀, 슬라이드 노트
- [ ] 찾기·바꾸기 상자, 글꼴 이름 상자(`맑은` 입력 → 목록 거름)에서 입력
- [ ] 결과 파일을 Word·Excel·PowerPoint에서 열어 같은 글인지

실제 IME는 **손으로만** 확인한다 (출시 관문):
- OS 키 입력을 흉내 내는 자동 도구(설계 초안의 `scripts/dev/ime-send.ps1`)는 저장소에 두지 않고 돌리지도 않는다 — 키가 다른 창(사용자가 쓰는 창)으로 갈 수 있어서. 실험판 `tmp/spike-cryptpad/scripts/ime-send.ps1`도 쓰지 않는다.
- 자동 시험(`OFFICEKIT_EDITOR_SMOKE=1`)은 CDP 조합 흉내(`Input.imeSetComposition`)로 '판정'·'세종'·'한글'만 본다. 실제 MS IME 두벌식·세벌식·한자 변환은 위 목록을 사람이 한다.

### 2.2 복사·붙여넣기

- [ ] Word 문단(굵게·색·표 포함) → 문서 편집: 서식이 대체로 유지
- [ ] Excel 범위(수식·서식) → 표 편집: 값·서식 유지, 수식은 값 또는 수식
- [ ] 한글(HWP) 문단·표 → 문서 편집 (한컴오피스에서 직접 복사)
- [ ] 웹 브라우저 글 → 문서 편집 (그림이 있으면 그림이 바깥 주소에서 받아지지 않고 빈 칸이거나 빠짐 — 밖으로 나가지 않는 것이 맞다)
- [ ] 편집 창 → Word·메모장으로 복사
- [ ] 마우스 오른쪽 메뉴 '붙여넣기', 편집 메뉴 '붙여넣기'(Ctrl+V 말고)

### 2.3 인쇄 · 내려받기

- [ ] 문서·표·슬라이드 각각 Ctrl+P → PDF가 기본 PDF 앱으로 열림, 한글이 □가 아님, 쪽 수가 맞음
- [ ] PDF 앱이 없는 PC(또는 연결을 끊고) → 저장 대화상자로
- [ ] 파일 → 다른 형식으로 내려받기 → PDF·ODT·RTF·TXT·PNG: 저장 대화상자, 저장한 파일이 열림
- [ ] 다른 이름으로 저장(같은 형식): 창 제목이 새 이름, 원래 파일 그대로

### 2.4 큰 문서 · 성능

- [ ] 50쪽 docx (표·그림 포함): 열기 시간 ____초, 스크롤 끊김 없음, 저장 시간 ____초
- [ ] 1만 행 xlsx: 열기 ____초, 맨 끝으로 이동(Ctrl+End), 정렬, 저장
- [ ] 슬라이드 50장 pptx (그림 많음): 열기·슬라이드 쇼·저장
- [ ] 작업 관리자: 편집 창 하나 메모리 ____MB (약 0.5GB 예상)

### 2.5 화면

- [ ] 다크 모드 (Windows 설정): 편집 창 막대·대화상자·띠가 어둡게, 앱 테마 바꾸면 따라감
- [ ] 고해상도 150%·200%, 모니터 둘(배율 다름) 사이로 창 옮기기: 글자가 흐리지 않음, 클릭 위치가 맞음
- [ ] 창을 가장 작게(720×520): 막대가 겹치지 않음
- [ ] 터치 화면 PC(있으면): 창을 600px 아래로 줄이거나 확대해도 휴대폰 화면(phone mode)으로 바뀌지 않음 — 휴대폰용 파일은 묶음에서 뺐다
- [ ] Office 편집 창 5개 열기 → '메모리를 많이 씁니다' 안내, 모두 닫으면 주 창 상태 막대가 비워짐
- [ ] 정보 · 라이선스: 원 개발사·수정판일 수 있음·AGPL·소스 주소(설치된 판의 태그), 라이선스 원문 탭에서 고지 파일이 글로 보임, 링크를 누르면 묻고 기본 브라우저로
- [ ] 아래쪽 법적 고지 줄이 늘 보이고 한국어
- [ ] 이 PC 글꼴: 글꼴 목록에 맑은 고딕·바탕·굴림·함초롬바탕 등 한국어 이름과 미리보기 그림

### 2.6 저장 · 파일

- [ ] 읽기 전용 파일 → 보기 모드, 저장 단추 꺼짐
- [ ] Word에서 연 docx를 편집 창에서 저장 → '다른 프로그램이 쓰고 있어' 안내, 다른 이름으로 저장은 됨

## 3. 알려진 한계 (✗가 아님 — 설계 11장)

- 저장하면 x2t가 꾸러미를 다시 쓴다: `styles.xml`이 커짐, 한글·영문 사이 간격이 달라 보일 수 있음.
- 편집기 상태 막대의 '모든 변경 사항이 저장되었습니다'는 편집기 안 기록 이야기. 진짜 저장 상태는 위 막대('저장됨·저장 안 됨').
- 편집기 UI 일부(새 기능 풍선, 셀 스타일 이름)는 영어. 문서 언어 표시가 'English – United States'일 수 있음.
- 함께 편집·맞춤법 검사 없음. 변경 추적·메모·차트·SmartArt·필드·포함 개체는 시험 문서로 따로 확인한다.
